# Exora references

## Tooling

- [NeoForge 1.21.1 ModDevGradle MDK](https://github.com/NeoForgeMDKs/MDK-1.21.1-ModDevGradle/tree/d69737d705926b200c23769f0a674ff6379badb4) supplied the baseline versions and Gradle wrapper. Template attribution is in [TEMPLATE_LICENSE.txt](TEMPLATE_LICENSE.txt).
- [NeoForge 1.21.1 documentation](https://docs.neoforged.net/docs/1.21.1/gettingstarted/) is the version-specific reference for mod loading and APIs.
- [ModDevGradle](https://github.com/neoforged/ModDevGradle) documents run configuration and the NeoForge development toolchain.
- [Gradle release checksums](https://gradle.org/release-checksums/) documents the distribution checksum used by the wrapper.
- [Gradle GitHub Actions](https://github.com/gradle/actions) documents wrapper validation and CI caching.

## Design influences

- GregTech informs sequential tiers, reusable intermediates, and factory scale.
- HBM's Nuclear Tech Mod informs large industrial facilities, in-game hazard management, and late-game infrastructure.
- Exora uses original systems, names, and assets. The influences are design references and add no runtime dependencies.
