# Exora roadmap

| Milestone | Scope | Acceptance criteria |
| --- | --- | --- |
| Foundation | NeoForge scaffold, repository, CI, and design documents | A fresh checkout builds on Java 21 and produces an Exora JAR. GitHub Actions publishes the build artifact. |
| First industrial slice | Material forms, basic generator, powered processor, a small component chain, and first research gate | A new survival world can turn a vanilla input into a useful component and unlock the next workbench tier. The flow works on a dedicated server and survives a restart. |
| Electrical industry | Logistics, scalable power, diagnostic UI, and an Overworld survey site | A production line runs through exposed inventories and energy connections. Blocked outputs and insufficient power display actionable status. Teams can complete the first shared discovery. |
| Mechanized industry | Precision components, tooling, automation robots, vehicle service bay, first ground vehicle, and an original encounter | Players can research, assemble, operate, service, and recover a vehicle. Control and ownership work with multiple players. |
| Aerospace and atomic industry | Propeller aircraft, helicopters, jet aircraft, hazardous facilities, and in-game nuclear generators | Flight controls and vehicle lifecycle work in multiplayer. Facilities exercise protection and mobility. Reactor status and faults are visible and recoverable. |
| Fusion and Overworld endgame | Fusion, modular powersuits and mechs, exotic manufacturing, and an original boss chain | The final Overworld encounter requires capabilities produced by the factory. Late automation meets a measurable server tick and network budget. |
| Beyond the Overworld | Orbital staging, planetary expeditions, and later dimensions | A complete Overworld campaign can support a repeatable expedition with a clear return and recovery loop. |

Build one end-to-end survival slice per milestone before multiplying machine variants. Add balance tuning, effects, and accessibility as each feature becomes playable.
